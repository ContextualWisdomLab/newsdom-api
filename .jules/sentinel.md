## 2024-06-12 - Path Traversal Vulnerability in File Upload
**Vulnerability:** The application was extracting the filename from an uploaded PDF without first replacing Windows-style path separators (`\`). On a POSIX system (like the server where this API runs), backslashes are valid characters in filenames and are not treated as path separators by `Path(filename).name`. This means a filename like `..\..\etc\passwd` would be saved exactly as `..\..\etc\passwd` instead of `passwd`.
**Learning:** Python's `pathlib.Path().name` uses the path separators native to the operating system it is running on. Therefore, when handling file uploads from varied client operating systems (like Windows clients talking to a Linux server), it is crucial to manually sanitize both forward and backward slashes before attempting to extract the base name.
**Prevention:** Always sanitize user-provided filenames by explicitly replacing backslashes with forward slashes (e.g., `filename.replace('\\', '/')`) *before* extracting the base name with `pathlib.Path().name` to prevent path traversal vectors on POSIX systems.
