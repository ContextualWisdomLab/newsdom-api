## 2024-06-08 - Path Traversal via Backslashes on POSIX Systems
**Vulnerability:** A path traversal vulnerability was present in how file uploads were handled because `pathlib.Path(filename).name` on a POSIX system does not treat backslashes `\` as path separators. A malicious client could send a filename like `..\\..\\etc\\passwd`, which would be treated as a single filename, potentially allowing arbitrary file writes in the temporary directory context if parsed correctly or otherwise leading to unexpected behavior.
**Learning:** `pathlib.Path().name` behaves differently based on the OS it's running on. On POSIX systems, it won't strip paths that use backslashes.
**Prevention:** Always sanitize user-provided filenames by replacing backslashes with forward slashes (`filename.replace('\\', '/')`) before passing them to `Path().name` or relying on standard library path manipulation functions for validation, especially when the software might run on Linux/POSIX environments.
