새로운 도구: JSON DOM 요소 개수 확인용 CLI 구현

NewsDOM JSON 파일에 포함된 다양한 요소(페이지, 기사, 이미지, 블록 등)의 개수를
빠르게 확인할 수 있는 `count_dom.py` 스크립트를 `tools/` 디렉토리에 추가했습니다.

주요 변경 사항:
- `tools/count_dom.py` 추가: JSON을 파싱하여 요소 개수를 세고 결과를 출력하는 CLI 도구 구현
- `tests/test_tools_count_dom.py` 추가: 100% 테스트 커버리지를 만족하는 검증 코드 작성

이 도구는 구조 복잡도를 진단하고 대규모 DOM 검증 작업을 할 때 도움을 줍니다.
