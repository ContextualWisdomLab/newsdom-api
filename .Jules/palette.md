## 2025-06-13 - OpenAPI Swagger Enhancements for API DX
**Learning:** For backend-only FastAPI services, the Swagger UI is the primary user interface for developers. Enhancing OpenAPI metadata (titles, descriptions, tags, and parameter details) significantly improves Developer Experience (DX) and serves as an accessible documentation layer.
**Action:** Always enrich FastAPI app instances and endpoint decorators with rich descriptive metadata in headless applications.
