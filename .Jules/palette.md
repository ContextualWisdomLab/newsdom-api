## 2025-06-05 - Enhance OpenAPI Swagger UI DX
**Learning:** For backend-only API repositories without a frontend UI, Developer Experience (DX) essentially serves as User Experience (UX). Adding descriptions, versions, tags, and license info dramatically improves the autogenerated Swagger/OpenAPI documentation readability.
**Action:** Always verify and populate FastAPI app-level and endpoint-level metadata when implementing or reviewing UX for Python/FastAPI backend APIs.
