## 2024-05-17 - OpenAPI Metadata
**Learning:** For backend APIs without frontends, improving OpenAPI metadata (e.g., adding explicit error response schemas and app descriptions) provides immediate DX/UX value for developers using tools like Swagger UI or Redoc.
**Action:** Always verify if FastAPI endpoint exceptions are documented in the `@app.get/post` responses parameter to ensure client developers know what to expect.
