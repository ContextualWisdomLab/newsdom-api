## 2024-07-09 - OpenAPI Examples for DX
**Learning:** For backend-only services without a frontend UI, Developer Experience (DX) acts as the user experience. Adding explicit examples to OpenAPI schemas significantly improves API discoverability.
**Action:** Use the singular `example` key via `json_schema_extra={"example": <value>}` in Pydantic V2 `Field` declarations to populate representative values in the Swagger UI.
